# campaign-info.md template

Create once during campaign creation or import as the player's immutable world-building contract. It defines what the DM should and should not introduce or emphasize. It is not a campaign summary, party roster, character sheet, current-state record, plot outline, or prediction of relationship outcomes.

Use this shape:

    # <Player> Campaign Information

    **Player:** <current player name>

    ## World-Building Direction
    <The durable premise, genre, themes, technologies, magic, cultures, kinds of opportunities, and other material the player wants included.>

    ## World-Building Boundaries
    <Material, assumptions, themes, or directions the player does not want. Use None when the player establishes no exclusions.>

The Player field is optional. Both world-building sections are required once and in order. Keep them concise and grounded only in explicit player direction.

Never include active party composition, party dynamics, current relationships, character motivations, rewards, current stakes, current quests, current locations, current events, intended arcs, story-direction tests, or assumptions that a temporary circumstance should persist. Those belong in party files, character files, world canon, quests, chronology, or `resume.md` as applicable.

Always read this file when story mode begins. Never change it through play, import reconciliation, session closure, or inferred drift. Change it only when the user explicitly asks out of character to revise the world-building contract.
