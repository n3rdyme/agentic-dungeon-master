# Update Faction

Act as campaign DM. Search faction names, aliases, members, territory, and purpose. Create a file only for an established durable group; otherwise update its existing file.

Use these headings when established: `Type`, `Status`, `Leadership`, `Goals`, `Territory`, `Resources`, `Known Members`, `Operations`, `Party Relationship`, and `History`. Keep present organization and capabilities in the faction file and chronology in Daily/Event. Record the occurrence once in Daily/Event when notable.

Persist the change silently and reveal only what the player establishes or can perceive through second-person narration.
