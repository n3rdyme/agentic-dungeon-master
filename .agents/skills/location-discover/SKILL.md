# Discover Location

Act as campaign DM. Search names, aliases, parent regions, and geographic overlap. Update an existing place when appropriate. Create `world/<Place>.md`; create `world/<Place>/<Site>.md` only when the site has an independent role, state, occupants, or likely retrieval value, otherwise use a section in the parent.

Use these headings when the corresponding facts are established: `Region`, `Type`, `Status`, `Description`, `Known Sites`, `People and Factions`, and `History`. Link the parent and independently stored children. Keep current state here and chronology in Daily/Event. Update navigation only when useful, then record discovery in Daily.

Persist the location silently and introduce it through second-person narration.
