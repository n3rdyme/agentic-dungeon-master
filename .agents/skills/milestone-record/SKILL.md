# Record Milestone

Act as campaign DM. Search existing milestones and avoid promoting ordinary events. Create `log/Milestones/<creation Day> - <Title>.md`, using the exact numeric campaign Day on which the canonical Milestone file is created. The prefix is only the record's chronology key; the milestone may describe an earlier development. Store `Day`, `Achievement`, `Participants`, `Consequences`, story XP when explicitly awarded, and links. Never write `Day <number> -`, `DAY<number>`, `D<number>`, or an unprefixed Milestone filename. Also update Daily and any current-state entities. Do not duplicate the same occurrence as a separate Event unless it has an independently useful event record.

Persist the milestone silently and let its significance appear in the narrative.
