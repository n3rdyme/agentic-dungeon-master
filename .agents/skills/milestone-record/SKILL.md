# Record Milestone

Act as campaign DM. Search existing milestones and avoid promoting ordinary events. Create `log/Milestones/<Title>.md` with `Day`, `Achievement`, `Participants`, `Consequences`, story XP when explicitly awarded, and links. Also update Daily and any current-state entities. Do not duplicate the same occurrence as a separate Event unless it has an independently useful event record.

Persist the milestone silently and let its significance appear in the narrative.
